Desenvolvimento de uma aplicação em Python voltada ao controle financeiro pessoal, com o objetivo de facilitar o gerenciamento de receitas e despesas. O projeto permite o cadastro e o armazenamento de movimentações financeiras, a listagem dos registros e o cálculo automático do total de receitas, despesas e saldo disponível. Durante o desenvolvimento, foram aplicados conceitos fundamentais de programação, como listas, funções, estruturas condicionais e estruturas de reprodução, além da organização do código em funções independentes, buscando maior clareza, reutilização e facilidade de manutenção. O projeto foi desenvolvido com foco na aplicação prática dos conhecimentos adquiridos em programação e na construção de uma solução simples e funcional para um problema do cotidiano.
